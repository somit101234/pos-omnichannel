## 4. Issues Nghiêm Trọng

### P0 — Không kết nối Frontend-Backend

**Mô tả:** Toàn bộ web frontend dùng mock data, không có API client layer.

**Impact:** Không thể chạy E2E test thật, không thể demo sản phẩm.

**Số lượng:** 11 route pages + 7 components — tất cả mock.

**Gốc rễ:** `services/api.ts`, `stores/`, `utils/` không tồn tại.

### P0 — 6 backend modules thiếu controller

Categories, Inventory, Multi-store, Online-orders, Platform-import — chỉ có service layer, không có API endpoint.

**Impact:** Frontend không thể gọi API cho các chức năng này.

### P1 — Mobile app chưa code

Chỉ có package.json, chưa có bất kỳ screen/store/service nào.

**Impact:** US15 — Mobile App hoàn toàn chưa bắt đầu.

### P1 — Electron chưa hoàn thiện

Chỉ có skeleton main.js + preload.js + index.html. Chưa có React app trong renderer.

**Impact:** US desktop POS chưa hoạt động.

### P2 — Service layer dùng in-memory thay vì Prisma

13/15 module (trừ Shift và Staff) dùng in-memory Map/Array thay vì PrismaService.

**Impact:** Data không được lưu vào database thật.

### P2 — Auth mock password

Mobile-sync và Auth đều dùng `hashed_${password}` thay vì bcrypt thật.

### P3 — Invoice placeholder

`invoice.controller.ts` trả về string placeholder thay vì gọi service.

### P3 — Platform import chưa implement adapters

Chỉ có interface, chưa có Shopee/GrabFood/BeFood adapter.
